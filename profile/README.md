# Ayuntamiento de Aranda de Duero

**Administración abierta. Código público. Inversión pública, software público.**

El Ayuntamiento de Aranda de Duero publica aquí el software que desarrolla y mantiene con fondos públicos. Creemos que una administración eficiente es también una administración transparente: cualquier persona debe poder ver qué se está construyendo, cómo se gasta el dinero y qué decisiones técnicas se toman en su nombre.

## Por qué publicamos nuestro código

- **Transparencia:** el código desarrollado con dinero público debe ser público.
- **Reutilización:** otros municipios, administraciones o ciudadanos pueden aprovechar, auditar y mejorar lo que construimos.
- **Eficiencia:** evitamos duplicar esfuerzos y favorecemos la colaboración.
- **Rendición de cuentas:** publicar el trabajo es una forma de demostrar que se hace bien.

## Principio: inversión pública, código público

Todo el software financiado con fondos municipales se publica bajo licencias abiertas. Si el Ayuntamiento paga por su desarrollo, la ciudadanía es su propietaria legítima.
